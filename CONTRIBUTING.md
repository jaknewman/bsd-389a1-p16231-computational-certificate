# Reproducibility and review contributions

Please open an issue or submit a pull request with a concrete statement: the exact claim challenged or independently reproduced, script/compiler/Sage version, input hashes, command line, observed output and expected output, and any corrections. Keep a strict separation between `PASS (reported)`, `PASS (locally reproduced)`, algebraic proof, and conditional arithmetic inference.

Do not upload credentials, SSH keys, personal identity details beyond intended author attribution, or unreviewed large archives. See `DATA_AVAILABILITY.md`.
